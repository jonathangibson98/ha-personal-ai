# Personal AI for Home Assistant

A dedicated, standalone custom Home Assistant integration providing a personal AI assistant interface and automation platform.

![Logo](custom_components/personal_ai/logo.png)

## Installation

### Manual Installation
1. Copy the `custom_components/personal_ai` folder into your Home Assistant `/config/custom_components/` directory.
2. Restart Home Assistant.

### HACS Installation
1. Open HACS in Home Assistant.
2. Go to **Custom repositories** and add this repository URL.
3. Select **Integration** and click **Add**.
4. Search for **Personal AI**, install it, and restart Home Assistant.

## Setup
1. Go to **Settings > Devices & Services**.
2. Click **Add Integration** and search for **Personal AI**.
3. Fill in your parameters and complete setup.
